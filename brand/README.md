# droid247 brand

The mark is **One Eye Open**: a droid face sleeping with one eye open. It rests, but it keeps watch. Black and white only.

Every file here is generated by `build_brand.py` (needs `rsvg-convert` and Pillow). Change the geometry there and re-run; don't hand-edit outputs.

```
python3 brand/build_brand.py
```

## Logo (`logo/`)

| File | Use |
|---|---|
| `lockup-horizontal-{black,white}.svg` | Default logo: site header, docs, decks |
| `lockup-stacked-{black,white}.svg` | Square-ish spaces: splash screens, social avatars, merch |
| `wordmark-{black,white}.svg` | When the face already appears nearby |
| `mark-{black,white}.svg` | The face alone: avatars, small UI, watermark |

Use the black files on light backgrounds and the white files on dark ones. The eyes are cut out, so the background shows through them. Keep clear space of at least the face's eye height on every side. Don't recolour, stretch, outline or add effects.

The wordmark is custom geometry (not a font), and its `o` echoes the open eye.

## App icons (`icons/`)

| Platform | Files | Where they go |
|---|---|---|
| Web | `web/favicon.svg` (switches black/white with the browser theme), `favicon.ico`, `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png`, `site.webmanifest` | Site root; link from `<head>` |
| iOS | `ios/AppIcon.appiconset/` | Drop into `Assets.xcassets` |
| Android | `android/mipmap-*/`, `mipmap-anydpi-v26/`, `values/ic_launcher_background.xml`, `play-store-512.png` | Copy into `app/src/main/res/`; 512 px PNG for the Play Store listing |
| macOS | `macos/AppIcon.icns`, `AppIcon-1024.png` | App bundle / Xcode / Electron `icon` |
| Windows | `windows/droid247.ico` (16–256 px) | Executable / installer / Electron `icon` |
| Linux | `linux/hicolor/` (16–512 px + scalable SVG) | `/usr/share/icons/hicolor/`, referenced as `Icon=droid247` in the `.desktop` file |

Sizes of 48 px and under use a version with heavier eyes so they stay legible.
