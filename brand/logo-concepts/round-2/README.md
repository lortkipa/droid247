# Round 2: Cursor Droid and Visor Head

Refined versions of the two remaining candidates. Both use the same colours (black tile, white body, orange eyes `#FF5A1F`) and the same wordmark: "Droid247" in Outfit Bold with the dot of the i in eye orange.

Each folder contains:

| File | Use |
| --- | --- |
| `app-icon.svg` | App icon and avatar: the symbol on its black tile |
| `favicon.svg` | Version for 16–32 px with simplified proportions so details survive |
| `mark.svg` / `mark-dark.svg` | Symbol without a tile, for light and dark backgrounds |
| `lockup.svg` / `lockup-dark.svg` | Horizontal symbol + wordmark |
| `lockup-stacked.svg` / `lockup-stacked-dark.svg` | Stacked symbol + wordmark |
| `animated.svg` | App icon that blinks every 4 seconds, for loading screens |
| `expressions/` | `idle`, `working`, `blink`, `done`, `alert` for in-app states and notifications |

Folders: `cursor-droid/`, `visor-head-white/` (matches Cursor Droid's colours) and `visor-head-orange/` (alternate).
